# My First GitHub Project

A simple HTML web page created to practice Git and GitHub basics.

## Description
This project contains a basic webpage with a heading, a short paragraph,
and a button. It was made to learn how to create a repository, commit
changes, and push code to GitHub.

## Files
- `index.html` - the main web page
- `style1.css` - the style of index1.html page 
- `README.md` - project description

## How to Run
1. Clone the repository:
2. Open the project folder.
3. Double-click `index.html` to open it in your browser.

## What I Learned
- Creating a repository on GitHub
- Using `git add`, `git commit`, and `git push`
- Writing a README file in Markdown
