# Task2 - Hello World Project

A simple HTML project that displays a greeting message.

## Description

This is a basic HTML file that renders a simple web page with:
- A heading that says "Hello, World!"
- A paragraph with a simple message

## Files

- `index.html` - Main HTML file

## How to Use

1. **Clone or download** this repository
2. **Open the file** in your web browser:
   - Double-click `index.html`, OR
   - Right-click → Open with → Choose your browser
3. You should see the "Hello, World!" message displayed

## Technologies Used

- HTML5
- Basic web markup
